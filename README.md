# Power BI Data Analysis Dashboard

## Project Overview

This project is an interactive **Power BI dashboard** created to analyze **business area** and present meaningful insights through data visualization.

The main objective of the project is to transform raw data into an easy-to-understand dashboard that can help users identify trends, compare performance, and make data-driven decisions.

## Objectives

* Analyze and understand the given dataset
* Track important KPIs and performance metrics
* Identify trends and patterns in the data
* Create interactive visualizations for better analysis
* Present insights in a simple and business-friendly way

## Tools & Technologies

* **Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculated metrics
* **Data Visualization**

## Project Workflow

1. Imported the dataset into Power BI
2. Cleaned and transformed the data using Power Query
3. Prepared the data for analysis
4. Created calculated measures using DAX
5. Designed interactive charts and visualizations
6. Added filters/slicers for interactive analysis
7. Created the final dashboard to present key insights

## Dashboard Features

* KPI cards for important metrics
* Interactive charts and graphs
* Filters and slicers
* Trend analysis
* Category-wise comparisons
* Interactive data exploration

## Key Insights

* Data Scientist has the highest average salary among the listed job roles, followed by Data Engineer and Data Architect.
* Python is the most preferred programming language, with significantly more respondents choosing it than R, C/C++, JavaScript, or Java.
* The United States represents the largest share of survey respondents, followed by other countries, India, the United Kingdom, and Canada.
* Breaking into the data field is considered moderately challenging — the largest group of respondents rated the difficulty as Neither easy nor difficult (42.7%).
* Average work-life balance satisfaction is 5.74/10, indicating moderate satisfaction among data professionals.
* Salary satisfaction is lower at 4.27/10, suggesting that respondents are less satisfied with their compensation than with their work-life balance.
* The survey contains 630 respondents, with an average age of 29.87 years.


## How to Use

1. Download the `.pbix` file from this repository.
2. Open it using **Microsoft Power BI Desktop**.
3. Explore the dashboard using the available filters, slicers, and visualizations.
